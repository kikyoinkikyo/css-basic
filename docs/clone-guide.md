# 클론코딩 작업 가이드

## 한 영역을 만드는 순서

1. **관찰하기** — 원본 사이트에서 만들 영역을 정하고, 큰 상자부터 작은 상자 순서로 나눠 봅니다.
   종이에 네모를 그려 보면 좋아요.
2. **측정하기** — 개발자 도구(F12)에서 요소를 선택하고 `Computed`(계산됨) 탭에서
   너비·높이·여백·글자 크기·색상을 확인합니다. 숫자는 **추측하지 말고 확인한 값**을 씁니다.
   측정한 값은 `docs/reference/<영역>.md`에 적어 둬요. (템플릿: `docs/reference/README.md`)
3. **배치 먼저** — 색과 글꼴보다 **상자의 위치와 크기**를 먼저 맞춥니다.
   이때 연습용 배경색을 칠해 두면 상자 경계가 잘 보여요.
4. **꾸미기** — 글꼴, 색, 테두리, 그림자를 넣습니다. 색·크기는 먼저 `css/tokens.css`에 맞는 변수가 있는지 찾아보고 `var(--이름)`으로 써요.
5. **비교하기** — 원본과 내 화면을 나란히 띄워 다른 점을 찾습니다.
6. **정리하기** — 새로 배운 속성을 `README.md`에 적고 커밋합니다.

## 개발자 도구 사용 팁

| 하고 싶은 것 | 방법 |
| --- | --- |
| 요소 고르기 | Ctrl+Shift+C를 누르고 화면에서 클릭 |
| 값 바꿔 보기 | Styles 패널에서 숫자를 클릭하고 ↑/↓ 키 |
| 박스 모델 보기 | Computed 탭 위쪽의 상자 그림 (margin · border · padding) |
| flex 배치 보기 | Elements 패널의 `flex` 배지 클릭 |
| 마우스 올린 상태 보기 | Styles 패널의 `:hov` → `:hover` 체크 |
| 모바일 화면 보기 | Ctrl+Shift+M |

📖 [Chrome 개발자 도구 – CSS 보기 및 변경](https://developer.chrome.com/docs/devtools/css?hl=ko)

## 막혔을 때 체크리스트

- [ ] 선택자 이름에 오타는 없는가? (`.` 빠짐, 클래스 이름 철자)
- [ ] 개발자 도구에서 내 스타일에 **취소선**이 그어져 있지 않은가? → 다른 스타일에 졌다는 뜻 (명시도 확인)
- [ ] 속성을 **부모**에 써야 하는지 **자식**에 써야 하는지 확인했는가? (flex, position에서 자주 헷갈림)
- [ ] 인라인 요소(`a`, `span`, `img`)에 width/height를 줬는데 안 먹는가? → `display` 확인
- [ ] `position: absolute`가 엉뚱한 곳에 붙는가? → 기준이 되는 조상에 `relative`가 있는지 확인

## Claude 튜터에게 질문하는 법

좋은 질문에는 이런 내용이 들어 있어요.
- **어느 영역**을 만들고 있는지 (예: "헤더의 언어 선택 레이어")
- **원하는 모습**과 **지금 모습**이 어떻게 다른지
- 이미 **시도해 본 것**

힌트를 받아도 모르겠으면 "다음 힌트 줘", 정말 막히면 **"정답 보여 줘"** 라고 하세요.
