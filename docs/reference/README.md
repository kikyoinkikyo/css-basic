# 원본 사이트 참고 자료 (영역별)

> `hero.md` 하나로는 부족해요. 원본 사이트는 **영역마다 구조와 수치가 다르고, 자주 바뀌어요.**
> 그래서 영역을 시작할 때마다 이 폴더에 **참고 파일을 하나씩** 만들어요.

## 왜 영역마다 따로 만들까?

- **바뀐 걸 알아채려고**: 히어로처럼 원본이 바뀌면, 언제 기준으로 만들었는지 날짜가 남아 있어야 해요.
- **추측을 막으려고**: 크기·색은 개발자 도구로 **측정한 값만** 적어요. 측정하지 못한 값은 "측정 전"으로 둬요.
- **토큰을 고르려고**: 여러 영역에 같은 값이 반복되면 `css/tokens.css`로 옮겨요.
- **JavaScript 단계에서 다시 쓰려고**: 원본이 어떻게 **움직이는지**(클릭, 자동 넘김 등)도 적어 두면 나중에 JS로 만들 때 바로 쓸 수 있어요.
