# 11. W11 Flexbox ② — 개념 정리

> 연습한 곳: 대한민국 구석구석 메인 **AI 기사 요약** 영역 (2026-11-25)

| 개념 | 한 줄 뜻 | 예시 코드 | 자주 하는 실수 |
|---|---|---|---|
| `flex-wrap` | 아이템이 한 줄에 다 안 들어가면 다음 줄로 넘겨요. **부모**에 써요. | `.list { display: flex; flex-wrap: wrap; }` | 자식에 쓰거나, 아이템이 `flex: 1`(시작 크기 0)이라 한 줄에 다 들어가서 줄바꿈이 안 돼요. |
| `flex-grow` | 남는 공간을 나눠 갖는 정도예요. 기본값은 **0**(안 늘어남). | `.text { flex-grow: 1; }` | 기본이 0이라는 걸 잊고 "왜 안 늘어나지?" 해요. |
| `flex-shrink` | 공간이 모자랄 때 줄어드는 정도예요. 기본값은 **1**(줄어듦). | `.photo { flex-shrink: 0; }` | `width`만 주면 shrink가 1이라 좁은 화면에서 그보다 작아져요. |
| `flex-basis` | 늘거나 줄기 전 **시작 크기**예요. | `.text { flex-basis: 200px; }` | — |
| `flex` 줄임말 | 늘어남 · 줄어듦 · 시작 크기를 한 번에 써요. | `flex: 0 0 120px;` | `flex: 1`은 시작 크기가 0%라서 `flex-grow: 1`(시작 크기 auto)과 결과가 달라요. |
| Hug · Fill · Fixed | Figma Auto Layout 크기를 CSS로 옮기는 방법이에요. | Hug = 설정 없음 / Fill = `flex: 1` / Fixed = `flex: 0 0 크기` | Fixed를 `width`로만 만들어요. |
| `min-width: auto` | flex 아이템은 기본으로 **내용보다 작게 줄어들지 않아요.** | 안 줄어서 가로 스크롤이 생기면 `min-width: 0` | 내용(큰 사진 등) 때문에 우연히 안 줄어든 걸 "고정됐다"고 착각해요. |
| `order` | 화면 순서만 바꿔요. | `.item { order: 2; }` | Tab 키 순서는 HTML 순서 그대로라, 키보드 사용자에게 순서가 뒤섞여 보여요. |
| 여러 줄 말줄임 | 정한 줄 수가 넘으면 `…`로 잘라요. **네 속성이 한 묶음**이에요. | `display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden;` | `-webkit-line-clamp` 하나만 써서 안 잘려요. |
| `line-height` 상속 | 따로 안 쓰면 부모 값을 물려받아요. | `line-height: var(--lh-title);` | 글자 크기만 바꾸고 줄 간격을 안 정해, 상자보다 글자 덩어리가 커져요. |

## 이번에 받은 피드백
- 고정 크기는 `width`가 아니라 `flex: 0 0 값`으로 해요. 개발자 도구 Computed에서 `flex-shrink`가 0인지 확인해요.
- 숨겨야 하는 요소(설명 말풍선)가 보이면 줄 높이까지 바뀌어요. `display: none`으로 숨겨요.
- `line-height`는 상속돼요. 글자 크기를 정할 때 줄 간격도 같이 정해요.
- ⏸️ 카드 칸 `flex-shrink: 0`은 Swiper 연결 때 확인하기로 했어요.
